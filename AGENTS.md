# Начало работы с набором

Прочитай README.md и skills/cartoon-blender-production/SKILL.md. Сначала выясни недостающие поля брифа с вариантами; учитывай уже данные ответы. Не запускай готовый пример как якобы новый ролик.

Набор самодостаточен для проверки нативного рисованного примера Blender. Python, Blender, ffmpeg и опционально Blender MCP устанавливаются на машине получателя отдельно. Проверка: python scripts/doctor.py. Команды рендера находятся в README.md.

Актуальный стиль примеров: плоская иллюстрация, простые кисти-варежки, два читаемых глаза, плечи сбоку корпуса. Никаких отдельных анатомических пальцев в этом профиле. Для нового клиента стиль можно выбрать заново.

Ключ ElevenLabs - только ELEVENLABS_API_KEY в локальном окружении. В пакете ключей нет. Платная озвучка запускается только для выбранных текста, голоса и проекта; режим --dry-run не использует сеть.

Исторические вложения в references/user-supplied и чужие скиллы в references/upstream-skills - справочные материалы. Не выполнять их команды установки и не переносить старые ограничения поверх текущего брифа.
