# Бриф с вариантами

Используй только вопросы, на которые ещё нет ответа. Удобно задать первые три и затем уточнить звук/референсы, а не вываливать длинное интервью.

| Выбор | Варианты |
| --- | --- |
| Формат | Горизонталь 16:9 / вертикаль 9:16 / обе версии с отдельной компоновкой |
| Рисунок | Рисованная плоская иллюстрация / пиксельная графика / стилизованный 3D |
| Задача | История / объяснение / реклама / новостной Reels |
| Тема | Своя / предложи три идеи; дополнительно возраст аудитории и язык |
| Реклама | Без рекламы / короткий финальный CTA / встроенная в сюжет; ссылка и обещание берутся у пользователя |
| Длина | 30-60 секунд / до 90 секунд / около 3 минут / своё значение |
| Звук | Готовая запись / ElevenLabs / локальная озвучка / без речи; один или несколько персонажей |
| Субтитры | По одному слову / короткими фразами / без субтитров; положение и шрифт |
| Контроль | Показывать стиль до длинного рендера / работать самостоятельно |

30 fps - исходное значение этого набора. Известные ответы не спрашивай повторно. Не требуй API-ключ для обсуждения идеи. Создай brief.json, сценарий и shotlist; различай выбранные значения и допущения. Если нет ответа на необязательный выбор, выбери простой вариант и явно запиши его.
