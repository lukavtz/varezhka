# Ключи и переносимость

В этот пакет нельзя класть действующий API-ключ, личный `.env`, конфиг чужого клиента, содержимое менеджера паролей или секрет из старого чата. Каждый получатель использует свой аккаунт и свой ключ. Встроенный CLI читает секрет только из переменной окружения.

## Подключить ElevenLabs локально

Создайте API-ключ в своём аккаунте ElevenLabs и сохраните его локально. Не отправляйте значение агенту в переписке и не записывайте его в сценарий или README. [Рекомендации ElevenLabs по хранению ключа](https://elevenlabs.io/docs/eleven-api/guides/cookbooks/forced-alignment).

В PowerShell можно ввести значение без отображения на экране и передать его только текущему процессу терминала:

```powershell
$voiceSecret = Read-Host 'ElevenLabs API key' -AsSecureString
$env:ELEVENLABS_API_KEY = [System.Net.NetworkCredential]::new('', $voiceSecret).Password
Remove-Variable voiceSecret
```

В Bash/Zsh:

```bash
read -rs -p 'ElevenLabs API key: ' ELEVENLABS_API_KEY; printf '\n'
export ELEVENLABS_API_KEY
```

Запускайте голосовой скрипт из этого терминала. Для агента в отдельном GUI-процессе окружение терминала может быть недоступно: используйте предусмотренное клиентом хранилище секретов или запускайте CLI из подготовленного окружения. Сам факт ввода переменной не означает, что другой процесс её получил.

Если предпочитаете `.env`, храните его только локально, вне архива и Git. Поставляемый CLI намеренно не загружает `.env` автоматически: переменную должен передать ваш терминал или менеджер секретов. `.env.example` содержит только названия настроек и пустые значения.

## Перед передачей папки другому человеку

- Передавайте `.env.example`, не свой `.env`.
- Проверяйте текстовые файлы, JSON, логи и метаданные на случайно вставленные секреты. Не выводите найденное значение в отчёт; укажите только имя файла и номер строки.
- Папка `.git`, кэши, временные ответы API и настройки MCP компьютера автора не нужны получателю.
- Не переносите в новый проект платные запросы только потому, что ключ уже существует. Сначала должны быть выбраны текст, персонажи/голоса и объём озвучки в брифе.
- Если секрет уже попал в публичную переписку или архив, замените его в кабинете сервиса. Удаление строки из новой копии не отзывает старый ключ.

`--dry-run` у `scripts/elevenlabs_voice.py` не читает ключ и не открывает сеть. Обычный запуск делает один запрос генерации; автоматических повторов после сетевой ошибки нет. Проверки без платного вызова и реальная генерация должны быть раздельно отмечены в отчёте.
